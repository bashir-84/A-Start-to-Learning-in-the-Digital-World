# شروعی برای یادگیری در دنیای دیجیتال

لندینگ‌پیج فارسی و راست‌چین کارگاه مهارت‌های دیجیتال برای نوجوانان. این نسخهٔ ایستا است و به نصب، build یا سرور نیاز ندارد.

## انتشار مستقیم در GitHub Pages

1. فایل‌های داخل این بسته را در ریشهٔ یک repository قرار دهید؛ `index.html` باید مستقیماً در ریشه باشد.
2. در GitHub، به **Settings → Pages** بروید.
3. در بخش **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
4. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و ذخیره کنید.
5. پس از انتشار، آدرس سایت در همان صفحهٔ Pages نمایش داده می‌شود.

همهٔ لینک‌های CSS، JavaScript، آیکون و فونت نسبی به همین پوشه تنظیم شده‌اند؛ بنابراین روی GitHub Pages حتی وقتی سایت زیر آدرس repository منتشر شود، فایل‌ها درست پیدا می‌شوند.

## ویرایش

- متن، آیدی تلگرام، تاریخ، ساعت و هزینه: `index.html`
- رنگ، تایپوگرافی و نمایش موبایل: `style.css`
- رفتار اسکرول و انیمیشن‌ها: `script.js`
- فونت‌ها و آیکون: پوشهٔ `assets/`

دکمه‌های ارتباط به `https://t.me/bashiramrii` وصل هستند. تاریخ، ساعت و مبلغ فعلی قابل ویرایش‌اند. محل برگزاری در صفحه درج نشده است. مجوز فونت‌های ارائه‌شده را هنگام انتشار رعایت کنید.
